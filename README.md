# A-non-linear-cointegration-approach
Research on a non-linear cointegration approach using a hybrid MS-VECM for 2 regimes on exchange rates.
Granger's cointegration approach is based on assuming a linear relationship between variables. However, the assumption of linearity among financial variable in datasets is not always linear, and may experience underlying volatility during periods of shocks and crises making it highly inefficient and misleading to make decisions based.
This research project introduces a non-linear cointegration approach using a hybrid Markov-switching vector error correction model, a two-state regime Gaussian Mixture Hidden Markov model along with a Clayton copula, to show lower tail dependence among two exchange rates; BWP/USD and the ZAR/USD.N
R-Studio was used to perform tests such as Normality tests such as Anderson-Darling, Jarque-Bera. Tests for highly correlated returns, tests such as Spearman's rank correlation, Kendall's tau and Johansen's cointegration test, Lastly White's Neural Network test was used for capturing nonlinearity of exchange rates and nonlinear unit root tests such as KPSS test for a nonlinear adjustment function and the Perron's unit root test for detection of structural breaks were used.
Python was used to implement a hybrid two-state regime Markov switching vector error correction model. This involved using the Gaussian Mixture Hidden Markov model as to account for non-linearity found between exchange rates. The Clayton copula was also implemented and using the Expectation Maximization algorithm, a 2x2 transition probability matrix and estimation of parameters on the rate of adjustment to equilibrium was achieved. Thus, computing a lower tail dependency during episodes of shocks and crises and a positive non-linear adjustment over time showing cointegration of BWP/USD and ZAR/USD exchange rates.
